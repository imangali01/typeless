# Typeless

Диктовка в любое поле ввода Windows по горячей клавише — в духе [Aqua Voice](https://aquavoice.com/), но локально и бесплатно.

Нажали **Win+C** (клавиша микрофона на Keychron K8 шлёт именно её) → говорите → слова печатаются в поле,
где стоит курсор, пока вы говорите. **Win+C** ещё раз — стоп, **Enter** — допечатать и отправить.

## Установка

Скачайте `TypelessSetup.exe` и запустите: установка в профиль пользователя, права администратора не нужны.
В меню «Пуск» появится Typeless; повторный запуск ярлыка открывает настройки работающего приложения.
При первой диктовке скачивается модель Whisper (`base` ≈ 145 МБ).

## Возможности

- **Горячая клавиша** — по умолчанию Win+C (Copilot не открывается), меняется в настройках.
- **Живой ввод** на локальном `faster-whisper`: слово печатается, когда два прохода распознавания с ним
  согласны. Задержка ≈1–1.5 с на модели `base` (i5-13420H, без GPU).
- **Языки**: русский + английские термины, только русский, English, қазақша, автоопределение.
- **Профиль «Программист»** — модель подсказывается терминами кода (commit, deploy, API, React…).
- **Словарь**: свои термины, предложения новых терминов после диктовки, исправления «ттермен → термин».
- **Буфер обмена**: если курсор не в поле ввода, текст копируется в буфер (или всегда — по настройке).
- **Индикатор** на выбор: линия голоса, капля у курсора, киносубтитры, кольцо у мыши, классика.
- Второй движок — **диктовка Windows** (Win+H, облако Microsoft).

## Разработка

Python 3.12:

```powershell
conda create -p .venv python=3.12 -y      # или: py -3.12 -m venv .venv
.\.venv\python.exe -m pip install -r requirements.txt
.\.venv\python.exe -m typeless            # запуск с консолью
.\.venv\python.exe -m pytest              # тесты
powershell -ExecutionPolicy Bypass -File scripts\build.ps1   # exe + установщик (нужен Inno Setup 6)
```

Полезные скрипты: `scripts/bench.py` (скорость моделей), `scripts/simulate_stream.py` (живой режим на WAV),
`scripts/render_overlay.py` и `scripts/render_settings.py` (картинки UI).

Конфиг и лог: `%APPDATA%\typeless\`.

## Ограничения

- В окна, запущенные от администратора, Windows не пропускает ввод от обычного процесса.
- Казахский на модели `base` распознаётся слабо — выберите `small`.
- Позицию текстового курсора («Капля у курсора») сообщают не все приложения; тогда капля у мыши.
