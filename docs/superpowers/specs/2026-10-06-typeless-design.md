# Typeless — локальная живая диктовка по Win+C

Дата: 2026-10-06
Статус: MVP в разработке

> **Изменение для MVP (2026-10-06).** По решению пользователя первым движком распознавания стал системный
> движок Windows — тот же, что у Win+H (`Windows.Media.SpeechRecognition`, режим диктовки). Он бесплатный,
> но работает через облако Microsoft. Локальный Whisper (разделы ниже) — второй движок за тем же интерфейсом
> `Engine`, переключается в настройках. Добавлено окно настроек: горячая клавиша (по умолчанию Win+C),
> язык, живой режим, автозапуск.
>
> Живой ввод для движка Windows: подтверждённые слова промежуточных гипотез печатаются сразу; когда
> приходит финальный результат фразы (с пунктуацией), напечатанный хвост этой фразы исправляется
> Backspace'ами на финальный текст. Без живого режима печатаются только финальные фразы.

## 1. Цель

Личная утилита для Windows 11, вдохновлённая Aqua Voice. Нажатие клавиши микрофона на Keychron K8 (она отправляет Win+C) запускает диктовку; распознанные слова печатаются прямо в поле ввода, где стоит курсор, пока пользователь говорит. Повторное нажатие останавливает диктовку.

Критерии успеха:
- Win+C запускает/останавливает диктовку; Copilot при этом не открывается, меню «Пуск» не всплывает.
- Подтверждённые слова появляются в активном поле с задержкой ≈1–1.5 с после произнесения.
- Русская речь с английскими терминами распознаётся пригодно для работы (термины латиницей).
- Всё работает локально и бесплатно: никаких облачных API.
- Оверлей «таблетка» с волной и живым текстом, как в `animation.png` и `opacity_text.png`.

## 2. Ограничения и окружение

- Windows 11, Intel i5-13420H (8 ядер / 12 потоков), 15.7 ГБ RAM, только встроенная графика Intel UHD → распознавание на CPU.
- Языки: основной русский, вкрапления английских терминов. Казахский не поддерживаем.
- Бесплатно: только open-source компоненты, модели скачиваются один раз.
- Клавиатура Keychron K8 (обычная, не программируется) → переназначить клавишу нельзя, перехватываем Win+C в Windows.
- Мышь MX Master 4: кнопку Action Ring можно назначить в Logi Options+ на Win+C — отдельной поддержки в приложении не требуется.

## 3. Решения

| Вопрос | Решение | Почему |
|---|---|---|
| Распознавание | `faster-whisper` (CTranslate2), CPU, `int8` | Лучшее качество среди бесплатных локальных вариантов на CPU |
| Модель | `small` по умолчанию; `base` — запасная, если не укладываемся в задержку | Пересчёт каждые ~0.5–1 с; `large-v3-turbo` на этом CPU в живом режиме не успеет. Финальный выбор — по замеру в M1 |
| Язык распознавания | `language="ru"` + `initial_prompt` со словарём терминов | Фиксированный язык убирает ошибки автоопределения; prompt подсказывает написание английских терминов |
| Триггер | Низкоуровневый хук `WH_KEYBOARD_LL`, перехват Win+C | Win+C — системная комбинация, `RegisterHotKey` её не отдаёт |
| Режим | Переключатель: нажал — старт, нажал — стоп | Клавиша шлёт Win+C как мгновенный тап, «держать» нельзя |
| Живой ввод | LocalAgreement-2: печатаем только подтверждённые слова | Черновик модели меняется; стирать текст в чужих полях ненадёжно |
| Печать | `SendInput` с `KEYEVENTF_UNICODE` | Не трогает буфер обмена, работает в большинстве приложений |
| UI | PySide6 (Qt): безрамочное прозрачное окно поверх всех | Полупрозрачность, скругления, анимации свойств |
| Чистка текста | Простые правила, без LLM | В живом режиме нет времени на LLM; на CPU это слишком медленно |
| Язык и рантайм | Python 3.12 в venv | У Python 3.14 может не быть колёс для `ctranslate2`/`av`; проверяем в M1 и остаёмся на 3.12, если нет |

Отвергнуто: облачные API (платно, не локально), встроенная диктовка Win+H (не локальная, хуже с английскими терминами, нет своего UI), Electron + whisper.cpp (тяжелее и дольше до рабочей версии), PowerToys/AutoHotkey (лишняя фоновая программа).

## 4. Архитектура

Один процесс, Qt-приложение в трее. Главный поток — Qt event loop (он же даёт message loop для хука). Распознавание — в отдельном рабочем потоке. Обмен между потоками — через Qt-сигналы.

```
Win+C ─▶ hotkey ──signal──▶ controller ──▶ audio (старт/стоп)
                                 │             │ PCM-чанки + уровень
                                 │             ▼
                                 │        streaming (рабочий поток)
                                 │          ├─ transcriber (faster-whisper)
                                 │          └─ LocalAgreement-2
                                 │             │ confirmed / tentative
                                 ▼             ▼
                              overlay ◀──── controller ──▶ cleanup ──▶ typer (SendInput)
```

### Модули (`typeless/`)

| Модуль | Ответственность | Зависит от |
|---|---|---|
| `hotkey.py` | Ставит `WH_KEYBOARD_LL` через `ctypes`; при Win+C глушит событие и шлёт сигнал `toggled`. Чтобы одиночное отпускание Win не открыло «Пуск», при перехвате инжектирует фиктивную клавишу (`VK 0xE8`). Колбэк хука только эмитит сигнал — Windows снимает хук, если колбэк дольше `LowLevelHooksTimeout`. | `ctypes`, Qt |
| `hotkey_logic.py` | Чистая функция-автомат: (состояние модификаторов, событие) → (глушить?, триггер?). Тестируется без Windows. | — |
| `audio.py` | Запись 16 кГц моно `float32` через `sounddevice`; отдаёт чанки и RMS-уровень для волны. | `sounddevice`, `numpy` |
| `transcriber.py` | Обёртка над `WhisperModel`: загрузка модели один раз, `transcribe(audio, prompt) → [Word(text, start, end)]` с `word_timestamps=True`, `vad_filter=True`. | `faster-whisper` |
| `streaming.py` | Цикл LocalAgreement-2: каждые `step_s` (0.5–1 с) пересчитывает аудиобуфер, сравнивает с предыдущей гипотезой, общий префикс → `confirmed`, остальное → `tentative`. Обрезает буфер по концу подтверждённого предложения, буфер не длиннее 30 с. На стоп — финальный проход, весь хвост становится `confirmed`. | `transcriber` |
| `agreement.py` | Чистые функции LocalAgreement: сравнение гипотез, сдвиг подтверждённой границы. | — |
| `cleanup.py` | Правила: убрать паразиты («ээ», «эм», «ммм»), двойные пробелы, заглавная буква в начале диктовки, пробел перед новым фрагментом. | — |
| `typer.py` | `type_text(str)`: строка → массив `INPUT` с `KEYEVENTF_UNICODE` (суррогатные пары для символов вне BMP) → `SendInput`. Построение массива — чистая функция. | `ctypes` |
| `overlay.py` | Окно PySide6 снизу по центру экрана: «таблетка» (синий кружок + волна по RMS) и под ней 2–3 строки текста курсивом. Новый текст выезжает снизу (сдвиг ~8 px + opacity 0→1, ~200 мс). Прозрачность строк по возрасту: новая строка 1.0, старше — 0.6, ещё старше — 0.35. Черновой хвост — светлее подтверждённого. Окно не забирает фокус (`WindowDoesNotAcceptFocus`, `WS_EX_NOACTIVATE`), клики проходят насквозь. | PySide6 |
| `controller.py` | Состояния `idle → recording → finishing → idle`. Запоминает окно-цель (`GetForegroundWindow`) на старте. Получает confirmed-фрагменты, чистит, печатает; передаёт тексты и уровни в оверлей. | все выше |
| `config.py` | `%APPDATA%\typeless\config.json`: модель, `step_s`, словарь терминов, автозапуск. Значения по умолчанию в коде. | — |
| `app.py` | Точка входа: `QApplication`, трей (`QSystemTrayIcon`: статус, «Автозапуск», «Выход»), предзагрузка модели при старте, автозапуск через `HKCU\...\Run`. | все выше |

## 5. Поток данных одной диктовки

1. Win+C → хук глушит событие → `toggled` → controller: `idle → recording`, запоминает окно-цель, стартует запись, показывает оверлей (fade-in снизу).
2. Аудио копится в буфере; каждые `step_s` рабочий поток распознаёт буфер.
3. LocalAgreement выдаёт новые подтверждённые слова → cleanup → `SendInput` в активное поле. Оверлей показывает подтверждённое ярко и черновой хвост бледнее.
4. Повторное Win+C → `finishing`: запись останавливается, финальный проход, остаток печатается.
5. Оверлей держит текст ~1 с и плавно исчезает → `idle`.

## 6. Ошибки и крайние случаи

| Ситуация | Поведение |
|---|---|
| Нет микрофона / нет доступа | Оверлей показывает ошибку 2 с, уведомление в трее; остаёмся в `idle` |
| Модель ещё грузится при нажатии | Оверлей «Загрузка модели…», запись всё равно идёт; распознавание стартует после загрузки |
| Фокус ушёл в другое окно во время диктовки | Перестаём печатать; остаток диктовки копируем в буфер обмена, уведомление «Текст в буфере» |
| Окно-цель запущено от администратора (UIPI блокирует `SendInput`) | Известное ограничение; в README. Обход — запускать Typeless от администратора |
| Тишина | `vad_filter` отбрасывает её; если за всю диктовку нет слов — оверлей просто исчезает |
| Распознавание не успевает за `step_s` | Следующий шаг стартует по готовности (шаги не копятся); задержка растёт, но ничего не теряется |
| Хук снят Windows (таймаут колбэка) | Колбэк только эмитит сигнал; дополнительно — периодическая проверка и переустановка хука |
| Диктовка длиннее 30 с | Буфер обрезается по подтверждённой границе — длина не ограничена |

## 7. Тестирование

- **Юнит-тесты (pytest), без железа:** `agreement.py` (префиксы, исправления, финализация), `cleanup.py`, `hotkey_logic.py` (Win+C глушится, Win+другая клавиша — нет, последовательности нажатий), построение `INPUT`-массивов в `typer.py` (кириллица, латиница, эмодзи/суррогаты).
- **Бенчмарк `scripts/bench.py`:** время распознавания 5/10/20 с записи для `base`/`small`/`medium` на этом CPU → выбор модели и `step_s`.
- **Интеграционный тест streaming:** проигрываем WAV-файл чанками в `streaming.py` с реальной моделью, проверяем итоговый текст и что подтверждённые слова не откатываются.
- **Ручной чек-лист:** Win+C в Блокноте, Chrome, Slack, VS Code; Copilot и «Пуск» не открываются; смена фокуса; окно от администратора; 2-минутная диктовка.

## 8. Вехи

1. **M1 — основа и замер.** venv, зависимости, хук Win+C (глушение + отсутствие «Пуска»), запись с микрофона, `bench.py`. Итог: подтверждённая работа хука и выбранная модель.
2. **M2 — живой ввод.** `transcriber`, `agreement`, `streaming`, `cleanup`, `typer`, `controller`; консольная версия без UI.
3. **M3 — оверлей.** Таблетка с волной, строки с градиентом прозрачности, анимации.
4. **M4 — трей и автозапуск.** `app.py`, `config.py`, словарь терминов, README.

## 9. Вне рамок

Казахский язык; облачные API; чистка/стилизация через LLM; режим «держать для записи»; голосовые команды («Send it»); история диктовок; установщик (.exe) — можно позже через PyInstaller; поддержка macOS/Linux.
